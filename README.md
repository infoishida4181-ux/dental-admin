# 歯科行政管理システム / 施設基準管理アプリ

歯科保険診療における施設基準の管理を支援する、単一HTMLベースの管理アプリです。

## 目的

- 各歯科医院が届出済み施設基準を一覧で管理できるようにする
- 診療報酬改定に伴う再届出、経過措置、要件確認を見落としにくくする
- 関東信越厚生局のPDF名簿から、自院の届出済み施設基準を取り込みやすくする
- 定例報告、講習会・研修期限、届出履歴をまとめて確認できるようにする
- 将来的な行政事務支援機能の基盤にする

## 現在の主な機能

- `index.html` 単体で動作する施設基準届出台帳
- 令和8年度改定を前提とした改定影響の確認
- 定例報告の記録管理
- 講習会・研修の受講記録と期限管理
- 厚生局PDFからの届出済み施設基準取込
- JSONエクスポート / インポートによるバックアップと復元
- ベースアップ評価料関連の入力補助

## 技術的な前提

- 単一HTMLファイルで動作
- ブラウザ上で利用
- 主な保存先は `localStorage`
- PDF解析には `pdf.js` を使用

## 今後の予定

- 現行HTML版の安定化と保守性向上
- バージョン更新時のデータ移行の安全性向上
- 利用者向けヘルプ、バックアップ手順、エラー報告導線の整備
- クラウド化を見据えたフロントエンド / バックエンド分離設計
- 医院ごとのデータ分離、認証、監査ログの導入検討
- 社労士確認を前提とした労務・社会保険関連支援機能の検討

## GitHub運用上の注意

このリポジトリには、実運用データや個人情報を入れないでください。

- 医院ごとのバックアップJSON
- 厚生局から取得したPDF原本
- スタッフ名、給与、賃金改善情報
- 社会保険、労災、マイナンバー関連情報
- 個人情報を含むExcelや添付資料

GitHubには、ソースコード、設計メモ、ドキュメント、ダミーデータだけを置く運用を前提にしてください。

## 開発方針

- `index.html` の機能とデザインは安易に変えない
- `localStorage` 構造、JSON入出力仕様、PDF取込仕様は変更時に慎重に扱う
- 小さな変更単位で履歴を残し、影響範囲を明確にする
- 法律判断が必要な領域は、最終的に専門家確認を前提にする
